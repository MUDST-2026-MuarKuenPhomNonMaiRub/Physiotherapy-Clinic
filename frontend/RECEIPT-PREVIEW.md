# ทดลองใบเสร็จ (frontend)

งานนี้เพิ่มรูปแบบใบเสร็จ A4 ตามภาพอ้างอิง ยังไม่สร้างเลขใบเสร็จหรือเปลี่ยนข้อมูลใน backend

## เปิดดู

จากโฟลเดอร์ `frontend` รัน:

```powershell
npm run dev -- --hostname 127.0.0.1 --port 3002
```

- เปิด `http://127.0.0.1:3002/receipt-preview` เพื่อดูข้อมูลสมมติ ไม่ต้องเข้าสู่ระบบ
- ข้อมูลจริง: เข้าสู่ระบบ → Transactions → กด **พิมพ์ใบเสร็จ** ในแถวรายการ หรือเปิดรายละเอียดรายการแล้วกดปุ่มเดียวกัน
- หลังชำระเงิน: กด **พิมพ์ใบเสร็จ** ในหน้าชำระเงินสำเร็จได้ทันที
- ปุ่มแสดงสำหรับบัญชีที่มีสิทธิ์ `transaction.view`
- เว็บหลักในเครื่องใช้ Docker ที่ `http://localhost:3000` และเปิดตัวอย่างได้ที่ `/receipt-preview` เช่นกัน หลังแก้โค้ดต้องรัน `docker compose up -d --build --no-deps frontend` จากโฟลเดอร์รากเพื่ออัปเดตเฉพาะ frontend ส่วนพอร์ต 3002 ใช้สำหรับ dev server ที่อัปเดตตามไฟล์ทันที
- กด **พิมพ์ / บันทึก PDF** เลือก A4 แนวตั้ง ขนาด 100% ปิด Headers and footers ของเบราว์เซอร์ และเปิด Background graphics หากต้องการพื้นสีตามแบบ
- มือถือเลื่อนใบเสร็จในแนวนอนได้ เพื่อรักษาสัดส่วนกระดาษ

## ข้อมูลและข้อจำกัด

- ดึงยอดรวม/ส่วนลด/รายการจากธุรกรรมเดิม ไม่บันทึกธุรกรรมใหม่ ไม่แก้การคิดเงินหรือคอมมิชชัน
- เลขอ้างอิงใช้ `transactionNo` ส่วนเลขที่เอกสารเว้นไว้ จึงแสดงฉบับร่าง
- ข้อมูลคลินิกและผู้ป่วยมาจากข้อมูลปัจจุบัน ยังไม่มี snapshot สำหรับใบเสร็จย้อนหลัง
- ใช้โลโก้ที่มีอยู่ในโปรเจกต์ ไม่ได้คัดลอกโลโก้จากภาพ
- ราคา/หน่วยเป็นยอดรายการหารจำนวน ข้อมูลหน่วย รหัสบริการ และส่วนลดต่อหน่วยยังไม่ครบ จึงไม่สมมติขึ้น
- ส่วนลด/ค่าบริการเพิ่มเติมเป็นบรรทัดแยกตามข้อมูลจริง
- เลขใบอนุญาต เลขผู้เสียภาษี อีเมล ภาษี แต้ม วงเงิน และผู้ลงชื่อยังไม่มีแหล่งข้อมูลในงานนี้ แสดง `—` หรือเว้นช่องไว้ ไม่ตีความภาษีเป็นศูนย์
- รายการ VOID แสดงข้อความยกเลิกและเหตุผล ยอดเดิมมีไว้ตรวจสอบเท่านั้น
- วันเวลาพิมพ์ใช้เวลา Bangkok และอัปเดตเมื่อกดพิมพ์ รวมถึง Ctrl+P
- เลขหน้าพิมพ์ใช้ CSS page counters ในเบราว์เซอร์ที่รองรับ รูปแบบข้ามหน้าขึ้นกับเบราว์เซอร์ ควรดู Print Preview ก่อนพิมพ์รายการยาว

## ไฟล์สำหรับตรวจงานก่อน commit ในภายหลัง

- `src/components/receipts/receipt-view.tsx` — รูปแบบใบเสร็จและคำอ่านยอดเงินบาท
- `src/components/receipts/receipt.module.css` — สไตล์เฉพาะใบเสร็จและการพิมพ์
- `src/app/receipt-preview/page.tsx` — ตัวอย่างข้อมูลสมมติ
- `src/app/(app)/transactions/[id]/receipt/page.tsx` — อ่านข้อมูลรายการจริงภายใต้ session และสิทธิ์ transaction.view
- `src/app/(app)/transactions/[id]/page.tsx` — เพิ่มปุ่มเปิดใบเสร็จ
- `src/app/(app)/transactions/page.tsx` — ปุ่มใบเสร็จในตารางและการ์ดมือถือ
- `src/app/(app)/checkout/page.tsx` — ปุ่มใบเสร็จหลังชำระเงินสำเร็จ
- `RECEIPT-PREVIEW.md` — คู่มือนี้

ไม่รวม `tmp/` (ภาพและสคริปต์ตรวจงาน), `deploy/k8s/` หรือไฟล์อื่นที่ไม่เกี่ยวข้องใน commit ใบเสร็จ
